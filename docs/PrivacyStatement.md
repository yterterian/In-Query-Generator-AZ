

# Privacy Statement - Enhanced In-Query Statement Generator

**Last updated:** [30/05/2025]

---

## Overview

We are committed to protecting your privacy. This privacy statement explains what data our VS Code extension **"Enhanced In-Query Statement Generator"** collects, how we use it, and your choices regarding this data collection.

---

## Data Collection

### What We Collect

Our extension collects minimal, anonymous usage data to help improve functionality and user experience:

- **Feature Usage:** Which commands you use (e.g., Copy as IN Statement, Paste Special)
- **Performance Metrics:** Duration of SQL generation operations
- **Error Information:** Error types and frequencies (without personal details)
- **System Information:** VS Code version, extension version, operating system
- **Usage Patterns:** When the extension is activated/deactivated
- **Configuration Usage:** Enabled settings (e.g., data type detection, formatting options)

### What We **DO NOT** Collect

We never collect:

- Personal information (e.g., names, emails, addresses)
- SQL code, data values, or database content
- File contents, names, or paths
- Workspace or project details
- Clipboard contents or pasted data
- Database connection information
- Any sensitive or identifying information

---

## How We Use Your Data

- **Improve Features:** Understand which SQL generation features are most valuable  
- **Fix Bugs:** Identify and resolve common issues with IN statement generation  
- **Performance:** Optimise extension speed and reliability  
- **Development:** Guide future feature development for SQL tools  

---

## Your Privacy Controls

### Opt-Out Options

You can disable data collection in two ways:

#### VS Code Global Setting

- Open **Settings** → Search `"telemetry"`
- Set `telemetry.telemetryLevel` to `"off"`

#### Extension-Specific Setting

- Open **Settings** → Search `"inQueryGenerator.telemetry"`
- Uncheck `inQueryGenerator.telemetry.enabled`

---

## Data Anonymisation

- All user identifiers are anonymised using one-way hashing  
- No data can be traced back to individual users  
- Session data is temporary and not linked across sessions  

---

## Data Storage and Security

- Data is stored securely using industry-standard encryption  
- Hosted on **Supabase** with enterprise-grade security  
- Automatic data retention limits (data older than 12 months is deleted)  
- No data is shared with third parties  

---

## Data Retention

- **Raw telemetry data:** Deleted automatically after 12 months  
- **Aggregated statistics:** Retained indefinitely (non-identifiable)  
- **Error logs:** Deleted after 6 months  

---

## Your Rights

You have the right to:

- Opt out of data collection at any time  
- Request information about the data we collect  
- Request deletion of any data associated with your anonymous identifier
